# 阿里云 RDS MySQL 配置指南

## 前置准备

1. 注册阿里云账号
2. 已购买 RDS MySQL 实例（实例ID：rm-bp123xjpzd5i0d4t9）
3. 实例所在区域：华东1（杭州）

---

## 一、创建数据库

### 1. 登录 RDS 控制台

1. 访问 [阿里云 RDS 控制台](https://rdsnext.console.aliyun.com/)
2. 找到实例 `rm-bp123xjpzd5i0d4t9`
3. 点击实例ID进入详情页

### 2. 创建数据库

1. 左侧菜单选择 **数据库管理**
2. 点击 **创建数据库**
3. 填写信息：
   - 数据库名：`duiniang_db`
   - 字符集：`utf8mb4`
   - 排序规则：`utf8mb4_unicode_ci`
4. 点击 **创建**

### 3. 创建数据库账号

1. 左侧菜单选择 **账号管理**
2. 点击 **创建账号**
3. 填写信息：
   - 账号名：`duiniang_user`（或自定义）
   - 密码：设置强密码并牢记
   - 账号类型：**普通账号**
4. 点击 **创建**

### 4. 授权数据库

1. 在账号列表中找到刚创建的账号
2. 点击 **授权**
3. 选择数据库 `duiniang_db`
4. 权限选择 **读写**
5. 点击 **确定**

---

## 二、初始化数据库表

### 1. 连接数据库

使用以下方式连接数据库：

**方式一：DMS（推荐）**
1. 在 RDS 控制台，点击 **登录数据库**
2. 使用 DMS 登录
3. 选择数据库 `duiniang_db`

**方式二：本地客户端**
使用 Navicat、MySQL Workbench 等客户端连接：
- 主机：`rm-bp123xjpzd5i0d4t9.mysql.rds.aliyuncs.com`
- 端口：`3306`
- 用户名：`duiniang_user`
- 密码：你设置的密码
- 数据库：`duiniang_db`

### 2. 执行建表 SQL

将 `docs/database.sql` 文件中的内容复制并执行。

---

## 三、配置白名单

### 1. 获取 Render 出口 IP

部署 Render 后，获取服务器出口 IP：
- 方式一：在 Render Shell 中运行 `curl ifconfig.me`
- 方式二：查看 Render 文档中的 IP 列表

### 2. 添加白名单

1. 在 RDS 实例详情页，左侧菜单选择 **数据安全性**
2. 选择 **白名单与安全组** 标签
3. 在 **白名单设置** 区域，点击 **添加白名单**
4. 填写：
   - 白名单分组：`default` 或新建分组
   - 白名单IP列表：填入 Render 出口 IP
5. 点击 **确定**

### 3. 验证白名单

添加白名单后，等待 1-2 分钟生效，然后从 Render 测试连接数据库。

## 四、安全建议

### 1. 账号安全

- 使用强密码（包含大小写字母、数字、特殊字符）
- 定期更换密码
- 不使用 root 账号连接应用

### 2. 网络安全

- 仅添加必要的 IP 到白名单
- 不要使用 `0.0.0.0/0`（允许所有 IP）
- 定期检查并清理不需要的白名单 IP

### 3. 数据备份

1. 左侧菜单选择 **备份恢复**
2. 配置自动备份策略
3. 建议每天备份一次

## 五、监控与维护

### 1. 监控指标

在实例详情页，左侧菜单选择 **监控与报警**，可以查看：
- CPU 使用率
- 内存使用率
- 磁盘使用率
- 连接数
- IOPS

### 2. 慢 SQL 分析

1. 左侧菜单选择 **性能优化**
2. 查看慢 SQL 列表
3. 优化执行效率低的查询

### 3. 空间管理

1. 左侧菜单选择 **数据库管理**
2. 查看各数据库占用空间
3. 必要时清理历史数据

## 六、常见问题

### 1. 连接超时

**问题**：无法连接到 RDS 实例

**解决方案**：
- 检查白名单是否添加了当前 IP
- 检查实例状态是否正常
- 检查网络是否通畅

### 2. 连接数过多

**问题**：`Too many connections`

**解决方案**：
- 升级实例规格
- 优化应用连接池配置
- 检查是否有连接泄漏

### 3. 空间不足

**问题**：磁盘空间不足

**解决方案**：
- 清理历史数据
- 升级存储空间
- 优化表结构

## 八、费用说明

RDS MySQL 费用包括：
1. **实例费用**：根据规格（CPU、内存）计费
2. **存储费用**：根据磁盘空间计费
3. **备份空间**：免费额度通常够用
4. **公网流量**：如果使用公网连接会产生流量费

建议：
- 开发测试使用按量付费
- 生产环境使用包年包月更划算
- 关注阿里云优惠活动
