## 第一阶段：阿里云 RDS MySQL 配置

### 1.1 登录阿里云控制台

1. 打开浏览器，访问 https://rdsnext.console.aliyun.com/
2. 使用你的阿里云账号登录
3. 找到实例 `rm-bp123xjpzd5i0d4t9`（华东1杭州）
4. 点击实例ID进入详情页

### 1.2 创建数据库

1. 在左侧菜单点击 **数据库管理**
2. 点击右上角 **创建数据库** 按钮
3. 填写信息：
   - 数据库名称：`duiniang_db`
   - 支持字符集：选择 `utf8mb4`
   - 排序规则：选择 `utf8mb4_unicode_ci`
4. 点击 **确定** 完成创建

### 1.3 创建数据库账号

1. 在左侧菜单点击 **账号管理**
2. 点击右上角 **创建账号** 按钮
3. 填写信息：
   - 账号名称：`duiniang_user`
   - 密码：设置一个强密码（**请牢记，后面需要用到**）
   - 确认密码：再次输入密码
   - 账号类型：选择 **普通账号**
4. 点击 **确定** 完成创建

### 1.4 授权数据库给账号

1. 在账号列表中找到刚创建的 `duiniang_user`
2. 点击右侧的 **授权** 按钮
3. 在弹窗中勾选数据库 `duiniang_db`
4. 权限选择 **读写**
5. 点击 **确定** 完成授权

### 1.5 初始化数据库表

**方式一：使用 DMS（推荐）**

1. 回到 RDS 实例详情页
2. 点击右上角 **登录数据库** 按钮
3. 系统会打开 DMS 数据库管理工具
4. 在左侧选择数据库 `duiniang_db`
5. 将以下 SQL 语句复制到查询窗口并执行：

```sql
-- 1. 卖家表（管理员表）
CREATE TABLE IF NOT EXISTS sellers (
    id INT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) NOT NULL UNIQUE COMMENT '用户名',
    password_hash VARCHAR(255) NOT NULL COMMENT '密码哈希',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='卖家管理员表';

-- 2. 对联商品表
CREATE TABLE IF NOT EXISTS products (
    id INT PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(200) NOT NULL COMMENT '对联标题/名称',
    description TEXT COMMENT '对联描述',
    price DECIMAL(10, 2) COMMENT '价格',
    image_urls TEXT COMMENT '商品图片URL，多个用逗号分隔',
    video_url VARCHAR(500) COMMENT '书写演示视频URL',
    status TINYINT DEFAULT 1 COMMENT '状态：1-上架，0-下架',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='对联商品表';

-- 3. 买家预定订单表
CREATE TABLE IF NOT EXISTS orders (
    id INT PRIMARY KEY AUTO_INCREMENT,
    order_no VARCHAR(50) NOT NULL UNIQUE COMMENT '订单编号',
    product_id INT NOT NULL COMMENT '商品ID',
    buyer_name VARCHAR(50) NOT NULL COMMENT '买家姓名',
    buyer_phone VARCHAR(20) NOT NULL COMMENT '买家手机号',
    buyer_address VARCHAR(500) NOT NULL COMMENT '收货地址',
    custom_remark TEXT COMMENT '自定义对联备注',
    status TINYINT DEFAULT 0 COMMENT '订单状态：0-待处理，1-处理中，2-已完成，3-已取消',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    FOREIGN KEY (product_id) REFERENCES products(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='买家预定订单表';

-- 4. 插入默认管理员账号（密码：admin123）
INSERT INTO sellers (username, password_hash) VALUES
('admin', '$2b$12$LJ3m4ys3Lz0QJNi8N0uYAeJ8d8vKz3X9J9v8X8X8X8X8X8X8X8X8X8');

-- 5. 创建索引
CREATE INDEX idx_products_status ON products(status);
CREATE INDEX idx_orders_product_id ON orders(product_id);
CREATE INDEX idx_orders_status ON orders(status);
CREATE INDEX idx_orders_buyer_phone ON orders(buyer_phone);
```

6. 点击 **执行** 按钮
7. 确认执行成功，无报错

## 第二阶段：部署后端到 Render

### 2.1 推送代码到 GitHub

1. 在 GitHub 创建一个新仓库，命名为 `duiniang`

2. 在本地将代码推送到 GitHub：

```bash
# 进入项目目录
cd F:\ai\duiniang

# 初始化 Git 仓库
git init

# 添加所有文件
git add .

# 提交代码
git commit -m "初始化对联预定售卖系统"

# 设置主分支
git branch -M main

# 添加远程仓库（替换为你的 GitHub 用户名）
git remote add origin https://github.com/你的用户名/duiniang.git

# 推送代码
git push -u origin main
```

### 2.2 创建 Render Web Service

1. 打开 https://render.com 并登录
2. 点击右上角 **New** 按钮
3. 选择 **Web Service**
4. 点击 **Connect account** 连接你的 GitHub 账号
5. 授权 Render 访问你的仓库
6. 找到并选择 `duiniang` 仓库
7. 点击 **Connect**

### 2.3 配置 Render 服务

填写以下配置信息：

| 配置项 | 填写内容 |
|--------|----------|
| **Name** | `duiniang-api`（或你喜欢的名称） |
| **Region** | `Singapore`（选择离中国最近的区域） |
| **Branch** | `main` |
| **Root Directory** | `backend` |
| **Runtime** | `Python` |
| **Build Command** | `pip install -r requirements.txt` |
| **Start Command** | `uvicorn main:app --host 0.0.0.0 --port $PORT` |
| **Instance Type** | `Free`（测试用）或 `Starter`（生产用） |

### 2.4 配置环境变量

1. 在创建页面找到 **Environment Variables** 部分
2. 点击 **Add Environment Variable**
3. 逐个添加以下变量：

| 变量名 | 变量值 |
|--------|--------|
| `DB_HOST` | `rm-bp123xjpzd5i0d4t9.mysql.rds.aliyuncs.com` |
| `DB_PORT` | `3306` |
| `DB_USER` | `duiniang_user` |
| `DB_PASSWORD` | `你的数据库密码` |
| `DB_NAME` | `duiniang_db` |
| `JWT_SECRET_KEY` | `一个随机字符串，如：my-super-secret-key-2024` |
| `JWT_ALGORITHM` | `HS256` |
| `JWT_EXPIRATION_HOURS` | `24` |
| `UPLOAD_DIR` | `./uploads` |
| `MAX_FILE_SIZE` | `10485760` |

4. 点击底部的 **Create Web Service** 按钮

### 2.5 等待部署完成

1. Render 会自动开始构建和部署
2. 等待日志显示 `Build successful` 和 `Deploy successful`
3. 部署完成后，页面顶部会显示服务地址，格式如：`https://duiniang-api.onrender.com`

### 2.6 获取 Render 出口 IP

1. 在 Render 服务详情页，点击左侧菜单 **Shell**
2. 在 Shell 中输入：`curl ifconfig.me`
3. 记录返回的 IP 地址

### 2.7 配置 RDS 白名单

1. 回到阿里云 RDS 控制台
2. 在左侧菜单点击 **数据安全性**
3. 选择 **白名单与安全组** 标签
4. 点击 **添加白名单**
5. 填写：
   - 白名单名称：`render`
   - 白名单IP列表：填入刚才获取的 Render 出口 IP
6. 点击 **确定**
7. 等待 1-2 分钟让配置生效

### 2.8 验证后端部署

1. 在浏览器访问：`https://duiniang-api.onrender.com/`
   应该看到：`{"message":"对联预定售卖系统 API","version":"1.0.0","docs":"/docs"}`

2. 访问：`https://duiniang-api.onrender.com/docs`
   应该看到 API 文档页面

3. 访问：`https://duiniang-api.onrender.com/health`
   应该看到：`{"status":"healthy"}`

**如果以上页面都能正常显示，说明后端部署成功！请记录你的后端地址，后面需要用到。**

## 第三阶段：部署前端到 Cloudflare Pages

### 3.1 修改前端 API 地址

在部署前端之前，需要将前端代码中的 API 地址改为你的 Render 后端地址。

**需要修改的文件（共7个）：**

**买家端（4个文件）：**

1. 打开 `frontend/buyer/app.js`，找到第3行：
```javascript
const API_BASE_URL = 'https://your-render-app.onrender.com';
```
改为：
```javascript
const API_BASE_URL = 'https://duiniang-api.onrender.com';  // 替换为你的实际地址
```

2. 打开 `frontend/buyer/detail.js`，同样修改第3行

3. 打开 `frontend/buyer/order.js`，同样修改第3行

4. 打开 `frontend/buyer/query.js`，同样修改第3行

**卖家端（3个文件）：**

5. 打开 `frontend/seller/login.html`，找到第95行左右的：
```javascript
const API_BASE_URL = 'https://duiniang.onrender.com';
```
改为你的实际地址

6. 打开 `frontend/seller/products.js`，同样修改第3行

7. 打开 `frontend/seller/orders.js`，同样修改第3行

### 3.2 推送修改后的代码

```bash
# 添加修改
git add .

# 提交
git commit -m "更新前端API地址"

# 推送
git push
```

### 3.3 创建 Cloudflare Pages 项目

1. 打开 https://dash.cloudflare.com 并登录
2. 在左侧菜单找到 **Workers & Pages**
3. 点击 **Create application**
4. 选择 **Pages** 标签
5. 点击 **Connect to Git**

### 3.4 连接 GitHub 仓库

1. 如果第一次使用，需要授权 Cloudflare 访问 GitHub
2. 选择你的 `duiniang` 仓库
3. 点击 **Begin setup**

### 3.5 配置构建设置

| 配置项 | 填写内容 |
|--------|----------|
| **Project name** | `duiniang`（或你喜欢的名称） |
| **Production branch** | `main` |
| **Framework preset** | `None` |
| **Build command** | （留空） |
| **Build output directory** | `frontend` |

### 3.6 部署

1. 点击 **Save and Deploy**
2. 等待部署完成（通常只需要1-2分钟）
3. 部署成功后会显示访问地址：`https://duiniang.pages.dev`

### 3.7 验证前端部署

1. 访问买家端：`https://duiniang.pages.dev/buyer/`
   应该看到商品列表页面（初始为空）

2. 访问卖家后台：`https://duiniang.pages.dev/seller/login.html`

## 🔧 常见问题解决

### 问题1：后端部署失败

**症状**：Render 显示 Build failed

**解决方案**：
1. 查看 Render 的构建日志，找到具体错误
2. 常见原因是依赖安装失败，检查 `requirements.txt` 格式
3. 确保 Python 版本兼容

### 问题2：数据库连接失败

**症状**：访问 API 显示数据库错误

**解决方案**：
1. 检查环境变量是否正确配置
2. 确认 RDS 白名单已添加 Render 出口 IP
3. 确认数据库账号密码正确
4. 确认数据库已创建并授权

### 问题3：前端页面空白

**症状**：访问前端页面显示空白或加载失败

**解决方案**：
1. 打开浏览器开发者工具（F12），查看 Console 错误
2. 检查 API 地址是否正确修改
3. 确认后端服务正常运行

### 问题4：跨域错误

**症状**：浏览器控制台显示 CORS 错误

**解决方案**：
1. 后端代码已配置允许跨域，通常不会出现此问题
2. 如果仍然报错，检查 Render 环境变量是否正确

### 问题5：图片无法显示

**症状**：商品图片位置显示空白

**解决方案**：
1. 检查图片URL是否正确
2. 如果使用外部图片，确保URL可公开访问
3. 如果上传图片，确保文件上传功能正常
